# 0002. Keyless Multi-Tile Providers with Leaflet

We use Leaflet with three public, API-key-free tile providers (OpenStreetMap Standard, OpenTopoMap, and Esri World Imagery) instead of commercial API-keyed vector tile services (such as MapTiler or Mapbox). This satisfies the Kriteria 2 Advance requirement for multiple tile layers via a layer control while eliminating the risk of submission rejection caused by expired, rate-limited, or misconfigured API keys during reviewer evaluation.
